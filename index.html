Kubíkovo přání

Veselé Vánoce

Přeji veselé vánoce všem, zde máte oslavnou píseň :>

U stromečku voní jedle, táta, máma, všichni vedle. Jenom děda Eman čeká, jestli ho dnes štěstí leká. Měkký dárky hází zpět, chce jen jedno pro ten svět! Když roztrhl papír zlatý, byl v tu ránu dojatý.

Pět set cigaret! Pět set cigaret! Pro Emana pod stromečkem zkrásněl celej svět. Žádný šály, žádný svetr, Eman skáče metr, metr! Pět set cigaret! To je, lidi, sen, bude „na vzduchu“ celej příští den!

Cítí se, jak kdyby stál a teď si konečně sed... Dostal totiž přesně – pět set cigaret!
